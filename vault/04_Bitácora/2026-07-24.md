## PDF de P2437-HV-DTS-001 REV0 — decisión de generación manual (2026-07-24)

- El usuario pidió inicialmente generar el PDF del DTS-001 a partir del Excel.
- Se evaluó generarlo vía LaTeX a partir del Markdown fuente
  (`Investigacion/Sistemas/hojas_datos/HD-VENT-001_ventilador.md`).
- Conclusión: un PDF-LaTeX no quedaría idéntico a la plantilla corporativa del
  Excel (encabezado con logos, celdas combinadas, fórmulas =PORTADA!).
- Decisión: el usuario generará el PDF manualmente desde Excel
  (`Archivo → Guardar como → PDF`, ambas hojas) para garantizar fidelidad al
  formato corporativo. Una vez generado, lo comunicará para registrarlo en el
  vault y copiarlo a `Emisiones/3.0 HV-HOJAS DE DATOS/`.
